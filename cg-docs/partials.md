# Index

Since we started reusing some texts on multiple pages, this folder contains various texts that can be embedded like this On our Developer Portal you'll be able to preview your game. It allows you to:

- Run your game as it would on CrazyGames

- Check if your game meets our requirements

- Test all the SDK features that you implemented and get feedback about it in other .md files. This is made possible by the plugin markdown_include, activated in mkdocs.yml. It is quite crappy and cannot parse too well .md files, so that's why the current files are HTML. But feel free to try to use .md partials also.
